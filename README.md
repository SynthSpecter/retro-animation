# **Retro Animation Studio 🎬**

**Un studio d'animation rétro pour créer des animations pixel art style années 90**
**A retro animation studio to create 90s-style pixel art animations**

---

## **📌 À propos / About**

### **Français**

**Retro Animation Studio** est un **studio d'animation pixel art** développé en **HTML5, CSS et JavaScript**, inspiré des jeux vidéo des années 80/90. Il permet de :

- **Créer des animations image par image** (frame-by-frame).
- **Dessiner avec des outils simples** (crayon, gomme, remplissage, sprites).
- **Appliquer des effets rétro** (scanlines, glitch, CRT).
- **Exporter en GIF ou PNG** pour partager vos créations.
- **Utiliser des sprites prédéfinis** (personnages, objets, effets).

### **English**

**Retro Animation Studio** is a **pixel art animation studio** developed in **HTML5, CSS, and JavaScript**, inspired by 80s/90s video games. It allows you to:

- **Create frame-by-frame animations**.
- **Draw with simple tools** (pencil, eraser, fill, sprites).
- **Apply retro effects** (scanlines, glitch, CRT).
- **Export as GIF or PNG** to share your creations.
- **Use predefined sprites** (characters, objects, effects).

## **🎬 Utilisation / Usage**

### **Créer une animation / Create an Animation**

1. **Dessinez votre premier frame** :
   - Sélectionnez un outil (crayon, gomme, etc.).
   - Dessinez sur la grille.

2. **Ajoutez des frames** :
   - Cliquez sur **"➕ Ajouter un frame"** pour ajouter un nouveau frame.
   - Dessinez le frame suivant.

3. **Prévisualisez l'animation** :
   - Cliquez sur **"▶ Lecture"** pour voir l'animation.
   - Ajustez les **FPS** (frames par seconde) avec le curseur.

4. **Exportez votre animation** :
   - Cliquez sur **"Exporter GIF"** ou **"Exporter PNG"**.
   - Choisissez un nom et une échelle, puis téléchargez.
